# Лабораторная работа № 3. Доска публикаций

## Файлы
- index.html — разметка страницы
- style.css — оформление
- app.js — вся логика (fetch, async/await, DOM)
- README.md — этот файл

## Как запустить
1. Открыть файл index.html в браузере (двойной клик)
2. Дополнительных серверов и установки не требуется — используется
   публичный тестовый API https://jsonplaceholder.typicode.com.

## Что реализовано
- Кнопка «Загрузить публикации»: GET-запрос
  https://jsonplaceholder.typicode.com/posts?_limit=5 через fetch + async/await,
  проверка response.ok, вывод заголовка и текста 5 публикаций через DOM.
- Форма «Создать публикацию»: проверка полей после trim(), preventDefault(),
  POST-запрос с JSON и заголовком Content-Type: application/json,
  проверка response.ok, вывод заголовка и ID из ответа.
- Состояния: «Загрузка...» / «Отправка...», сообщение об ошибке,
  повторный запрос (кнопки снова активны благодаря finally).

## Результаты проверки
1. Нажатие «Загрузить публикации» → появляются 5 записей с заголовками и текстом,
   сообщение «Загружено публикаций: 5».
2. Отправка пустых полей или одних пробелов → красное сообщение
   «Заполните заголовок и текст публикации», запрос не отправляется.
3. Отправка корректных данных → сообщение «Публикация создана! ID: 101...»
   (HTTP 201), публикация появляется в списке, форма очищается.
4. Проверка ошибки: в app.js заменить GET_URL на
   "https://jsonplaceholder.typicode.com/postz?_limit=5" → появляется
   «Не удалось загрузить данные: Ошибка сервера: 404», кнопка снова активна.
   После проверки адрес восстановлен.

Примечание: JSONPlaceholder имитирует создание — записи на сервере не сохраняются.
